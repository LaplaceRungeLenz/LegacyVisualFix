# 近战反馈 0.2.0：配置、兼容与收尾记录

本版本整合前四阶段反馈，并完成可见性／强度协调与兼容边界整理。不继续开发新协议、分类音效、血条、击杀强调或击退规则。

## 行为

服务端确认玩家近战造成生命或吸收损失后，仅向支持反馈协议的攻击者发送结果。客户端显示准星、局部粒子、可选模型倾斜和第一人称持物回弹。白色表示扣血，金色表示仅消耗吸收生命；混合损失使用白色。

保留旧版伤害、无敌帧、攻击输入、真实击退、实体位置及碰撞箱。模型反应是整体渲染矩阵倾斜，武器回弹是持物矩阵旋转；不冻结世界，不修改挥动计时。

## 配置与升级

关闭游戏后替换旧 JAR，只启用一个版本。保留 `config/legacyvisualfix/combat.cfg`，启动时补齐新字段；修改配置后重启。单机可直接使用，多人建议两端同版本。仍使用协议 v1。

`feedbackPreset` 默认 `custom`：继续读取原有各项参数，不覆盖用户已调好的手感。选择其他预设时只改变运行时有效值，保存的自定义参数仍保留；切回 custom 即恢复。单项功能开关、EFR 避让、粒子设置、最低亮度和排除名单始终优先。

| 参数 | light 轻量 | standard 标准 | strong 明显 |
| --- | --- | --- | --- |
| 单次粒子数 | 3 | 6 | 8 |
| 基础粒子大小 | 0.50 | 0.65 | 0.80 |
| 模型倾斜角／时长 | 1.5° / 120 ms | 3° / 140 ms | 4° / 160 ms |
| 持物回弹角／时长 | 1.5° / 100 ms | 3° / 120 ms | 4° / 140 ms |
| 准星提示时长 | 120 ms | 160 ms | 180 ms |
| 可选提示音音量 | 0.12 | 0.20 | 0.25 |

预设不会启用本来关闭的功能；音量只作用于本模组可选提示音，不修改 EFR 战斗音效。

### 可见性与限制

- `particleMinLight=6`，范围 0–15：只为命中粒子的方块光照分量设下限，保留天空光、深度遮挡和原生渲染路径。0 跟随环境光照，15 达到最高方块光值；不改世界照明，不提供透墙显示。Shader 可能有自己的亮度处理，不保证不同光影外观完全一致。
- `particleScale=0.65`，范围 0.25–1：custom 模式的基础大小。小目标额外缩小粒子，目标表面偏移和散布随尺寸调整，避免覆盖小怪；大目标受上限限制。
- 保留 4 tick 粒子寿命、单次最多 8 粒、滚动 200 ms 最多 32 粒、活动上限 32。粒子过期记录每 tick 清理，不必等下一次命中。最少粒子关闭、较少粒子减量。
- 模型反应和武器回弹使用同一帧时间采样，减少多遍渲染中的姿态差异。各自独立计时，不重置游戏 hurtTime；反应最多保存 128 个目标，角度不叠加失控。
- 原有 `particleMode=auto` 会在 EFR 伤害粒子启用或其状态无法可靠识别时避让；`always` 明确允许叠加，`off` 关闭。EFR 文件不被改写。

## 兼容排除项

| 配置 | 格式 | 作用 |
| --- | --- | --- |
| particleExcludedEntities | 实体注册名或完整 Java 类名 | 只关闭该实体的局部命中粒子 |
| reactionExcludedEntities | 实体注册名或完整 Java 类名 | 只关闭该实体的模型倾斜 |
| recoilExcludedItems | 物品注册名或完整 Java 类名；可加 @metadata | 只关闭该物品的持物回弹 |

均为精确匹配，忽略条目前后空格，不支持通配符。物品注册名使用 Forge 注册表中的完整名字；带 metadata 可只排除某一种 GT 工具，避免影响同一注册物品下的其他工具。名称应以实际注册信息为准。示例：

```text
S:particleExcludedEntities <
    Thaumcraft.Wisp
 >
S:reactionExcludedEntities <
    Thaumcraft.BrainyZombie
 >
S:recoilExcludedItems <
    minecraft:diamond_sword
 >
```

### 保留的限制

- 标准生命／吸收损失链路之外的虚拟护盾、自定义血量、完全绕过伤害钩子的攻击仍可能没有反馈。
- 模型倾斜跳过玩家、IBossDisplayData、死亡／隐形、骑乘／载客、高度大于 4 或宽度大于 3 的实体。小型自定义 Boss 若未实现该接口，应自行排除。
- 完全替换 RendererLivingEntity 或 Forge 持物渲染路径的模组可能没有对应视觉效果。外部渲染的附件、血条、特殊多部件不保证随模型倾斜；调用点缺失时允许只保留其他反馈。
- 持物回弹保留最近 250 ms 本地攻击匹配和同槽位物品检查；v1 没有攻击事务／武器 ID，同类物品极快替换与高延迟关联不能完全消歧。不确定时跳过回弹；不新增协议。
- 实体缺失、隐形、过远或生成时被遮挡可跳过局部粒子；粒子位置仍为包围盒估算，不是精确武器接触点。
- 独立多人服务器、低 TPS、极高延迟、全部 Boss 与渲染组合没有完整验收。数量有界不等于已完成性能基准测量。

## 收尾与验收方式

按用户要求，本轮仅编译／打包、静态代码审查和发行包核对，不运行游戏、测试套件或 CI。主分支现有金刚杵朝向修复和星形拖尾更新一并保留。没有修改用户实例的 JAR、配置或存档。

建议用户最终对照：白天／夜间、Photon 开关、particleMinLight=0/6、三个预设、牛／小型怪物／大型怪物、GT／TiC 武器及副手、连续攻击和退出重进。关注可见性、强度是否协调、模型／附魔层是否一致。异常对象可先用独立排除项处理；所有伤害与击退应保持原规则。

本功能线到此收尾。源代码通过 PR 合并至 main；GitHub Release 正文为空，仅附新版 JAR，配置及兼容说明保留在仓库。
