# 金刚杵九宫格交互

手持金刚杵指向 GT 机器、线缆或管道时，显示 GregTech 原生扳手/剪线钳九宫格。
右键按所指区域选择操作方向：机器和管道使用 GT 原生扳手路径，线缆使用剪线钳路径。
线缆切换会同步相邻线缆的对应连接端。潜行操作线缆仍只切换所选的一侧。
保留参考实现对 IC2 可调朝向机器、AE2 可旋转方块和 Forge 可旋转方块的朝向调整。

仅移植此项功能，不包含副手方块替换、连续挖掘保护、AE 部件拆卸或终端功能。
普通方块的原有右键行为和真正对空气潜行右键的精准采集切换不变。
支持 `gregtech.common.tools.ToolVajra` 和旧版 `gravisuite.ItemVajra` 及其子类。

## 安装与配置

- 多人游戏客户端和服务端均安装本版 ModernNH。单人游戏安装一个 JAR 即可。
- 集成在同时存在 GregTech、IC2 和 AE2 时注册，使用整合包自带依赖，不打包这些模组。
- `config/modernnh/vajra.cfg` 中 `vajra.enabled=true`，设为 `false` 并重启可关闭。
- 未支持本功能的服务器不会启用客户端九宫格或拦截原始交互；其他视觉功能仍可仅装客户端。
- 避免同时启用参考模组的 `vajraToolFunctions`，以免两个处理器争用同一次右键事件。

## 实现与验证

客户端使用 GT 原生 `BlockOverlayRenderer.drawGrid` 及全方块管线射线选择；精确点击坐标
通过独立网络通道送至服务端，在服务器 tick 中执行。服务端检查手持工具、坐标、交互距离、
方块编辑权限与 Forge 交互取消结果，并保留 GT 自身的机器使用权限检查。
队列容量和每 tick 处理数量有上限，并丢弃断线和跨维度后的过期请求。
GT 原生方法负责 GT 工具消耗和具体机器/管道规则；通用方块成功旋转消耗 1,000 EU。

编译目标：GT5-Unofficial 5.09.54.79、AE2 rv3-beta-1029-GTNH、IC2 2.2.828-experimental。
自动测试覆盖网络坐标合法性、距离边界及报文编解码；完整构建检查包括现有回归测试、格式与重混淆。
已对照 GT 编译依赖检查网格取消事件、管线权限和原生电量消耗。
尚未在完整 GTNH 客户端与专用服务器中进行手动世界交互验收。

人工验收：用九宫格中心、四边及角落调整六个面的机器朝向；对相邻线缆和液体/物品管道
反复连接/断开并重新登录；测试潜行、覆盖板、无电金刚杵、受保护区域、关闭配置及仅客户端安装。
