# 第二阶段：确认命中粒子测试方法

本阶段新增局部短粒子。白色表示本次实际生命损失，金色表示只消耗吸收生命；混合损失使用白色。粒子不是暴击或横扫判定，不增加伤害、攻击冷却、硬直、击退或范围攻击。

## 安装与配置

使用 `legacyvisualfix-0.2.0-combat.2.jar` 替换旧版 JAR，勿同时启用多个版本。单机直接安装；多人建议两端使用此版本。沿用第一阶段 v1 协议，旧版客户端仍只显示旧反馈；没有服务端反馈支持时不凭空生成命中粒子。

配置文件：`config/legacyvisualfix/combat.cfg`，修改后重启。

| 配置 | 默认 | 含义 |
| --- | --- | --- |
| client.particleMode | auto | EFR 伤害粒子关闭时使用本模组粒子；EFR 已开启或无法可靠识别时避免叠加 |
| client.particlesPerHit | 6 | 每次最多 1–8 粒；全局预算仍生效 |
| client.marker | true | 第一阶段准星提示，可单独关闭以观察新粒子 |
| client.debug | false | 可设 true 辅助核对实际 HP / ABS 损失 |

particleMode=off 可进行开关对照；always 是显式允许与 EFR 叠加。游戏视频设置“最少粒子”会关闭本阶段粒子，“较少粒子”减少数量。现有 EFR 音效不变。

## 建议亲测

1. 在独立测试世界，用普通武器打牛或僵尸，观察目标靠近玩家的一侧出现短白色粒子；连续挥动时，未实际造成损失的攻击不产生新的成功反馈。
2. 给目标吸收生命后攻击。只消耗吸收生命时为金色；开始扣血后为白色。
3. 对比 particleMode=off 与 auto：伤害、击退、攻击节奏应相同，仅局部粒子不同。
4. 用 GT 钢制小刀、匠魂大剑测试，再对比 Special Mobs、神秘时代、Ender Zoo 和暮色森林的常规怪物。
5. 开启、关闭 Photon 分别观察；把游戏粒子设置调为最少，确认粒子关闭但准星提示仍存在。

粒子位置依据客户端当前目标包围盒估算，不是精确刀刃接触点。不可见、过远或客户端已移除的目标会跳过局部粒子，准星确认仍可显示。高伤害不会无限增加粒子数量。

兼容范围按标准伤害链路和客户端实体可见性决定，不使用原版怪物白名单。自定义生命系统、完全绕过标准伤害方法、多部件代理和完整 Boss 阶段仍需单独验证；具体实测结果见第二阶段报告。
