# 0.3 主题与动画

沿用已批准的蓝灰渐变、中心布局和金色配色，仅更新以下部分：

- Logo 使用内置 imagegen 从原概念图重绘出的独立透明 PNG，保持 Jappa 像素轮廓、金色齿轮与蓝绿色地球。源资产和完整屏幕概念分离。
- 进度条默认高 6 GUI 像素，宽为屏幕 40%，金色 #E1BC62 与底色 #293B4B，不含倒角或多层高光。
- 淡入默认 200ms：GPU 缓存切换前已呈现画面，与完整加载画面平滑混合。
- 淡出默认 300ms：保留最终加载画面，叠加到后续正常游戏帧上逐渐隐去。异常离开也会清理会话，后续重载会替换旧动画。
- 两个时长独立配置，0 表示关闭，范围 0–2000ms。
- Angelica 可选 @Pseudo Mixin 必须在启动早期注册；Iris 在晚期 Mixin 阶段之前初始化。主配置由 manifest 注册，所有目标明确声明在 client 列表。
- 光影启停、切换和参数应用共用 Iris.reload 会话，独立光影管线重建单独处理；没有光影包的普通管线不显示光影加载界面。
- 完整未修改的 0.1 / 0.2 默认配置升级并备份；任何自定义键或值均保留。

Logo 使用内置图像生成工具，参考上一版概念图。提示词要求：仅提取并忠实重绘 Jappa 风格 NH 金色齿轮/蓝绿色地球徽标，保留 New Horizons 字样，透明背景、像素轮廓与金色分层；不包含标题、背景和进度条。来源及衍生美术许可见 META-INF/NOTICE-GTNH.md。

背景和进度条可用 tools/GenerateThemeAssets.java 复现。资源加载和光影编译仍由原有客户端线程执行；单个不可拆分的长编译步骤可能暂停刷新，不伪造按时间匀速推进的进度。
