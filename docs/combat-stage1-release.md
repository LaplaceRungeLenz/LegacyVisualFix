# LegacyVisualFix 0.2.0-combat.1

战斗反馈第 1 阶段预发布。基于最新 main 的 0.1.1 功能；保留普通物品银白色拖尾等已有改进。

- 服务器确认近战实际扣血后显示白色准星命中标记；仅消耗吸收心显示金色。
- 可选显示 HP / ABS 数值，帮助核对模组怪物和武器。
- 可选短确认音。默认检测 EFR 后不重复叠加，EFR 原有音效继续由 EFR 负责。
- 沿用原版及模组的伤害、无敌帧、AI、输入和击退；不加入冷却、粒子或模型后仰。
- 公共生物伤害路径适用于继承该流程的模组实体；完全绕过公共路径的攻击、自定义护盾、多部件 Boss 不保证覆盖。

多人需两端安装此版本；客户端单独安装不会猜测服务器伤害。替换旧 JAR，不要同时保留多个版本。

配置：`config/legacyvisualfix/combat.cfg`。默认启用，160 ms 标记。首次验收可设 `debug=true`、`durationMs=500` 后重启。

验证：46 项 JUnit 测试通过；Java 8 与 Java 25 + Angelica 2.1.25 / lwjgl3ify 3.0.10 / Hodgepodge 2.7.62 分别通过 14 项真实服务器行为检查和白色／金色标记的网络、绘制验证。正常 JAR 检查包含伤害映射、Java 8 字节码与 Smoke 类排除。

限制：尚未对完整 GTNH 的每个模组怪物和武器进行实测；独立专用服务器启动受 EULA 确认限制，未完成独立服运行验证。

详细测试步骤与逐项兼容范围见同一分支的 [combat-stage1-testing.md](combat-stage1-testing.md)。

本阶段交付后等待用户反馈，不继续开发下一阶段。
