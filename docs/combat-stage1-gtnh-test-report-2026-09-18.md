测试日期：2026-09-18。结论：本次覆盖范围内通过，未发现需要修改第一阶段战斗功能的 bug。尚未进入下一阶段开发，等待用户批准。

## 执行方法和结果

通过桌面控制启动游戏、创建独立世界 `新的世界 LVF Combat Stage1 QA`、进入世界、鼠标攻击、保存退出。没有进入用户原有的 `新的世界` 存档。

为可靠测量减血、吸收生命、事件次数和击退速度，在实际整合包中临时加载了可审计的测试插件。插件只对名称包含 `LVF Combat Stage1 QA` 的世界运行，调用真实玩家近战方法和真实模组实体类，并记录实际状态与本模组上报值。它不是仅以模拟对象替代模组的单元测试；但大部分批量目标没有执行自然生成初始化及完整 AI 生命周期。

| 检查 | 结果 | 实际覆盖范围 |
| --- | --- | --- |
| 伤害观察 | 39 项通过 | 21 种实体、4 种 Infernal 词缀、2 把模组武器、10 项机制检查、2 项网络提示 |
| 单次攻击开关对照 | 通过 | 生命、吸收生命、三轴速度、hurtTime、hurtResistantTime 相同 |
| 连续攻击开关对照 | 通过 | 30 tick 逐次攻击，逐帧状态序列相同；生命在第 0、10、20 tick 分别减 1 |
| Photon 开启 | 白色和金色提示通过 | 接收实际服务端消息后，截图及标记像素测量 |
| Photon 关闭 | 白色和金色提示通过 | 同上 |
| 鼠标攻击 | 通过 | 对测试牛真实左键攻击，吸收生命减少，金色提示及调试数值可见 |
| 正常构建 | 通过 | 46 项单元测试，0 失败、0 错误；正式 JAR 校验通过 |

批量检查核对上报 HP/吸收量与目标实际减少量，并检查事件是否恰好触发一次。环境伤害、玩家箭伤、FakePlayer 伤害及功能关闭时，即使目标实际减血也不产生本阶段近战反馈。无敌、事件取消、同 tick 无效重复攻击均没有误报。

连续攻击对照使用受控目标，手动推进受伤计时器；未模拟完整重力、AI 移动和网络输入。因此它支持“观察功能没有改变被测伤害、速度和受伤计时”的结论，不等于完成了高延迟联机或物理鼠标 20 CPS 连击测试。

自动截图时使用了局部黑色背景辅助像素判定，测试配置将提示延长至 500 ms。另有不依赖该像素判定的真实鼠标攻击截图。测试结束已恢复默认 160 ms 并关闭调试文字。不同 GUI 缩放、自定义准星、F1 隐藏 HUD 未逐项穷举。

EFR 配置启用了 combatSounds，本阶段 soundMode 为 auto，已有 EFR 时跳过额外提示音。本轮没有录音或实际听音验证，声音听感及是否重复播放不列为已实测通过。

## 测试中修正的测试工具问题

初轮测试插件未完整同步武器属性，且部分目标距离不正确，不能用作最终伤害判定。随后修正属性应用、玩家模式和目标位置；GT 工具常量也修正为实际存在的 KNIFE。第二轮 Vengeance 导致玩家位移，使后续网络目标超出距离，出现两项测试失败；最终轮改为相对玩家位置布置目标并清除测试位移后通过。

这些是测试工具问题，未据此修改战斗功能。最终结果使用第三轮 39 项伤害记录；有光影像素证据使用第一轮有效的两项网络截图，无光影证据使用第三轮。原始轮次记录均本地保留，没有掩盖失败轮次。
