# 战斗反馈第 1 阶段：可靠命中确认

版本：`0.2.0-combat.1`。分支：`codex/combat-feedback`。交付后等待玩家反馈，不继续第 2 阶段。

## 新增效果

- 本人近战实际消耗目标生命值后，准星周围出现约 160 ms 的白色四角标记。
- 仅消耗原版吸收心时为金色；同时扣血和消耗吸收心时为白色，调试文字分别显示两种数值。
- 没有实际损失时不产生成功标记。快速点击仍遵守原有无敌帧，不是每次点击都闪。
- 可选确认音使用原版 `random.successful_hit`，类似箭矢命中的短提示，并非新武器音效包。默认 `auto`：安装 Et Futurum Requiem（EFR）时不叠加提示音；未安装 EFR 时播放。不会接管、更改或修复 EFR 原有的事件前置音效。
- 本阶段不增加粒子、后仰、横扫或镜头震动；它是后续视觉增强的准确命中基础。

观察发生在公共 `EntityLivingBase.attackEntityFrom` 调用虚拟 `damageEntity` 前后；读取生命值与吸收值，不改写原调用参数。嵌套调用中可观察到的同目标损失会被扣除，防止重复计算。伤害、无敌帧、冷却、AI、真实位置、速度、碰撞箱和输入保持原有行为。

## 安装与配置

退出游戏，替换测试实例 `mods` 中旧 LegacyVisualFix JAR，只保留一个版本，不安装 sources/dev 包。

- 单机：客户端安装即可，本地服务器会加载公共模块。
- 多人：服务器与客户端都安装本阶段版本，才有准确命中确认。只装客户端时本阶段不推测伤害，原有视觉功能继续可用。
- 新服务器不会向未声明 `lvf_combat_v1` 通道的旧客户端发送本模块消息。
- 依赖沿用 Minecraft 1.7.10、Forge 10.13.4.1614、UniMixins 0.2.1+；GTNH 使用整合包配套环境。
- 首次启动生成 `config/legacyvisualfix/combat.cfg`，修改后重启。

| 分类 / 配置 | 默认 | 用途 |
|---|---|---|
| `combat.enabled` | `true` | 服务端控制观察，客户端控制呈现 |
| `client.marker` | `true` | 显示白色／金色命中标记 |
| `client.durationMs` | `160` | 标记时长，60–500 ms，不限制攻击频率 |
| `client.debug` | `false` | 显示最近一次确认的 HP / ABS 损失；2 HP = 1 心 |
| `client.soundMode` | `auto` | `auto` / `always` / `off` |
| `client.soundVolume` | `0.2` | 新增提示音音量，不改变 EFR 音量 |

第一次建议设 `B:debug=true`、`I:durationMs=500`，确认工作后改回默认。想听本模块声音可设 `S:soundMode=always`，这会主动与 EFR 音效叠加，默认不会如此。

## 游戏内验收

在开启作弊的测试世界准备围栏和怪物，再切到生存攻击。

1. **普通命中**：空手或普通剑攻击牛、僵尸、骷髅。扣血时闪白色，挥空不闪。调试 HP 应对应生命值下降；僵尸有护甲，伤害可能为小数。
2. **连击**：快速点击同一目标。标记随有效伤害刷新，不随每次点击刷新。对比禁用 `enabled` 后，伤害、节奏、击退和浮空应一致。
3. **完全免伤**：`/summon Cow ~ ~ ~3 {Invulnerable:1b}`。攻击不产生本模块成功标记，其他模组自己的音效不属于该断言。
4. **吸收心**：`/summon Cow ~ ~ ~3 {AbsorptionAmount:4.0f}`。空手间隔攻击，先出金色且 HP 为零，吸收耗尽后出白色。避免秒杀武器。
5. **其他伤害**：弓箭、着火、摔落不应被标记为你的近战命中；机器 FakePlayer、反伤也排除。
6. **模组武器**：GT 工具、匠魂武器重复前两项，重点观察多段、范围和附加伤害。若实际扣血但没有提示，记录武器与怪物名称。
7. **模组怪物**：分别测试 Special Mobs 普通变种、Infernal Mobs 强化怪、暮色普通怪和神秘时代普通怪。Boss 独立测试，不能由小怪推断。
8. **多人**：两人攻击同一目标，仅造成该次伤害者看到标记；旁观者不因别人攻击显示。重连、跨维度后不应残留旧标记。
9. **HUD**：测试 GUI 缩放、有／无光影和自定义准星。F1 隐藏 HUD 时不显示；打开界面时不显示。其他模组若完全取消 CROSSHAIRS 绘制事件，可能导致本标记无法呈现。

反馈请包含 GTNH / Java 版本、单机或多人、怪物所属模组、武器、能否实际扣血、标记颜色和调试数值；异常可附日志或短视频。体验反馈可说明是否太短、太亮、遮挡瞄准，以及连击是否保持原样。

|---|---|
| 原版普通生物公共伤害路径 | 实机 Forge 测试覆盖牛、护甲减伤、无敌帧、吸收心、事件取消 |

| 多部件 Boss、外层结算后回血／复活 | 取决于本体公共路径；不保证反映整个自定义外层攻击的最终结果 |

| 核心模组替换掉伤害调用位置 | 非强制观察钩子，该路径没有反馈，不因缺少观察钩子阻止启动 |
| Angelica 2.1.25 / lwjgl3ify 3.0.10 / Hodgepodge 2.7.62 | Java 25 开发组合已有端到端验证；不代表所有光影包或完整 GTNH 存档 |

## 验证记录

完整构建通过 **46 项 JUnit 测试（0 失败、0 错误）**。单元测试覆盖计量、嵌套扣除、异常清理、非有限数据、消息往返、序号去重、时效、连接身份、维度和队列上限。

`runClient -PcombatSmoke` 在 Java 8 真实 Forge/Mixin 环境通过 **14 项服务器行为检查**，另通过 FML 通道注册、实际 S2C 数据包、客户端主线程处理、白色／金色标记像素验证。测试还比较开关前后的生命值、吸收值、速度、hurtTime 和 hurtResistantTime。

Java 25 / Angelica 组合也通过同样的 **14 项服务器检查与白色／金色 HUD 验证**。现代组合命令：`runClient25 -PcombatSmoke -PangelicaSmoke -x setupHotswapAgent25`。`-x` 仅用于本机不安装 JDK hotswap agent，正式包无该依赖。测试报告在开发目录 `run/client/legacyvisualfix-combat-server-smoke.txt` 与 `legacyvisualfix-combat-client-smoke.txt`。必须检查最新报告 PASS 和进程成功退出，不应只看旧报告。

专用服务器启动器在缺少 EULA 同意时停止，未代用户接受协议，故**本次未完成独立专用服务器运行验证**。本地服务器链路不冒充独立服验收。未启动用户完整 GTNH 实例、未改动其存档或配置。

正常构建不带 Smoke 参数；发布检查拒绝测试类，验证 Java 8 字节码、公共 Mixin 注册、伤害方法映射和包版本。
